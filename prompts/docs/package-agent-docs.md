# Create or Update Package Agent Docs

Write documentation that lets a future agent use, configure, and maintain this project without guessing. Create a root AGENTS.md index that maps the repository and links to every area doc. Write one AGENT.md for each major package or area, including any plugin, provider, theme, skill, or extension system you find. Merge upgrades into existing docs instead of adding duplicates. A fresh agent should be able to answer operational questions, such as how to change the model or theme, from the docs alone.

- For each area, cover its purpose, entry points, and a code map of key files and ownership.
- Document configuration files, environment variables, and settings with verified examples.
- Give copy-paste setup and connection steps, plus common tasks with the edit and verify workflow.
- State the agent rules for that area and a troubleshooting section with real fixes.
- List verification commands that prove setup and changes work.
- Derive every claim from the code, scripts, and docs in the repo and fix stale docs you find.
