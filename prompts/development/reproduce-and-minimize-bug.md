# Reproduce and Minimize a Bug

Turn <bug report> into a minimal reproduction, a proven root cause, and a regression test. Write the smallest deterministic command, input, or test that fails, and capture the exact output and trigger conditions. Minimize the input, configuration, and code path to the smallest case that still fails. State the mechanism in one sentence before editing, then make the smallest change that addresses it. Add a regression test that fails on the old behavior and passes on the fix, and show me the before and after evidence.
