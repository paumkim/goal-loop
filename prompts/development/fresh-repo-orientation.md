# Fresh Repository Orientation

Build a short, durable map of this repository so future work starts from verified facts. Stay read-only and derive every statement from a file, never guessing a command or path. Map:

- what the project does, its language, runtime, and main data flow
- which directory owns each concern, and where entry points and generated files live
- the exact install, run, build, lint, typecheck, and test commands, marked verified or unverified
- where configuration and environment variables are defined, without real secret values
- the branch, commit, review, merge, and release rules
- missing or stale docs and anything that contradicts itself

Save the map where this project keeps maintainer or agent docs, or give it to me if there is no such place.
