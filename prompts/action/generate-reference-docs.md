# Generate Reference Docs

Generate this project's reference documentation from its code and annotations
using the repo's own docs generator. The generated docs should be current, cover
every changed public symbol or endpoint, and replace any hand-written copy that
has drifted. Change source comments or annotations rather than editing generated
files directly.

I should be able to confirm the generated links resolve and that no generated
file was hand-edited. If the repo has a docs-freshness check, run it and report
any gaps in coverage.
