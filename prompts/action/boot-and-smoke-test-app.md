# Boot and Smoke-Test the App

Get this project running from a clean checkout and prove it responds to a real
request. Install dependencies with the project's own package manager and
committed lockfile. Create any required config from the provided samples using
non-secret local values, then start the app with its documented dev command.
Probe a health or root endpoint, or the CLI's `--help` or version, and confirm
the expected status and body.

I should be able to follow the exact commands you used and reach a healthy app.
Stop any background process you start, and call out any setup docs that were
wrong or missing.
