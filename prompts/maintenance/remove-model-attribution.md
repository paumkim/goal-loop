# Remove AI Model Attribution Stamps

Clean the current repository of AI model attribution claims while preserving legitimate code and required literals.

## Remove
- Co-author/generated/contributor/written-by attribution lines and trailers referencing AI tools or models (e.g. `Co-authored-by`, `Generated with`, `Generated by`, model names/IDs, "AI assistant" footers).

## Keep
- Indented code blocks, quoted docs/changelog entries, or test fixtures where a literal string is required.
- If unsure whether a match is a required literal, keep it and flag it for review instead of guessing.

## How
1. Search the repository for attribution/model-name patterns (exclude `.git`, dependencies, and build artifacts as appropriate).
2. Delete only the attribution line/sentence. Do not rephrase unrelated code, comments, or logic.
3. Do not modify git history.

## Verify
- Re-run the search: no unintended hits remain outside justified/required literals.
- Run the repository's standard checks (e.g. typecheck/tests/lint as applicable).
- Show `git diff --stat` and `git status`.
