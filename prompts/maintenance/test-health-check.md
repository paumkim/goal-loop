# Check Test Health

Run this repository's tests and improve their health without lowering coverage or hiding failures. Record a baseline of passed, failed, skipped, and flaky results, then show me the before and after numbers. Fix each problem at its root cause and never delete, weaken, or skip a test to make the suite green.

- Correct either the code or the test, whichever is actually wrong.
- Re-enable skipped or `.only` tests that are safe and unblocked.
- Make flaky tests deterministic, or report them with reproduction steps.
- Add a focused regression test only for a real coverage gap in scope.
- List any tests still disabled and why.
