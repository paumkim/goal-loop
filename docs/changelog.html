Changelog

Recent changes to this repository, newest first. Rows are read from git log (git log -- docs/ README.md src/ scripts/), so the committed page can never drift from history. Uncommitted working-tree edits detected by the watcher are kept in a local, gitignored log (.docs-watch.log); view them with bun scripts/docs-watch.ts log.

The Last updated stamp in the footer of every docs page is regenerated from git log by bun scripts/docs-watch.ts once. Run it after committing, or keep bun scripts/docs-watch.ts watch running; it is event-driven (inotify via fs.watch), debounced, and idle when nothing changes.
