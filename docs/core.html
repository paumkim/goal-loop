Entry points

Root index.ts, tui.ts and rpc.ts re-export src/index.ts (the server plugin), the precompiled dist/tui.js (built from src/tui.tsx by bun run compile) and src/rpc.ts (the shared client contract), as OpenCode resolves plugin roots at the package root. src/index.ts is the only wiring site; src/tui.tsx is the native prompt.footer indicator, toasts and the /goal detail dialog.

compactor.ts

Auto-compacts the session when compactAtTokens is set: measures the estimated model-visible context after each turn and asks the host to compact; sweeps stale in-flight markers. Also compacts at every /goal-loop iteration boundary (compactOnLoopIteration, default on) and on restore of a live goal, so each iteration arms with a fresh context.

Both paths defer while work is in flight (a turn executing or background subagents/shells running; fails closed). compactAtBoundary returns a result object (requested + estimate/reason); force skips only the cooldown.

Exports: AutoCompactor (maybeCompact, compactAtBoundary).

src/runtime/compactor.ts

controller.ts

Goal state machine, turn loop, retries, check-ins, epoch guard, /goal-loop advance (met → summarize → arm next iteration; caps and guards), verifyMet verification gate before a met verdict is accepted. onCompactionLanded() settles pending boundary-compact tracking and, for a live active loop, queues a <goal-loop-reanchor> note (non-waking, non-interleaving) restating the objective, armed condition and iteration history after the host's context compaction.
