Entry points

Root index.ts, tui.ts and rpc.ts re-export src/index.ts (the server plugin), the precompiled dist/tui.js (built from src/tui.tsx by bun run compile) and src/rpc.ts (the shared client contract). OpenCode resolves plugin roots at the package root.

src/index.ts is the only wiring site. src/tui.tsx contains the ambient jump-row goal pill, the compact HUD card, toasts and the /goal detail dialog. The pill is a zero-flow absolute 1-row box on the empty left side of the host's jump-to-latest row, claimed through the session.composer.top slot; its leading icon begins the line at cell 0, on the same left rail as the card's hanging bar. The card is a bordered floating panel above the jump row; left click on the pill toggles it, Esc dismisses it.

When a goal reaches a terminal (or cleared) state, the intake path releases everything the goal armed: the HUD card disarms (its Esc layer and context menu reset), the pinned condition drops, and the finished record leaves the entries cache once the recent-terminal re-pull window lapses (expiredTerminalSessionIDs in src/core/hud.ts, applied on the 15s tick, dropSessions in src/core/entries.ts) — so no finished goal's chrome, pin or palette affordance carries over into the next request or the next version of the loop in the same session. The /goal detail dialog's loop · vN/M position chrome renders only while the loop is live; a finished loop shows its outcome instead.

The condition row copies to the clipboard on click. When the loop is hot (two missed boundary compactions) or a goal fails, both the card and the dialog show the exact remediation instead of a vague warning (a /compact-style hint, evaluator.verifyCommand or /goal clear). Model helpers live in src/core/hud.ts, the card in src/hud-card.tsx.

src/runtime

background.ts

Tracks running subagents and shells; decides when evaluation defers.

Exports: BackgroundTracker.

src/runtime/background.ts

compactor.ts

Auto-compacts the session when compactAtTokens is set. It measures the estimated model-visible context after each turn and asks the host to compact, and sweeps stale in-flight markers. Also compacts at every /goal-loop iteration boundary (compactOnLoopIteration, default on) — per session: only the session whose arm crossed the boundary is compacted, and a restore of live goals requests nothing.

Both paths defer while work is in flight (a turn executing or background subagents/shells running; fails closed). compactAtBoundary returns a result object (requested + estimate/reason); force skips only the cooldown.

Exports: AutoCompactor (maybeCompact, compactAtBoundary).

src/runtime/compactor.ts

controller.ts

Goal state machine, turn loop, retries, check-ins, epoch guard, /goal-loop advance (met → summarize → arm next iteration; caps and guards), verifyMet verification gate before a met verdict is accepted. onCompactionLanded() settles pending boundary-compact tracking and, for a live active loop, arms a one-shot ground-truth re-anchor (injected into the next model request by the context hook) after host compaction.

Exports: GoalController.

src/runtime/controller.ts

events.ts

Server-event router with replay dedup.

Exports: ServerEvent, createRouter (replay dedup is internal).

src/runtime/events.ts

evaluator.ts

Native per-turn verdict handling, optional consensus (a second vote on a separate model), and loop summarize/next-goal generation with per-attempt budgets and retry escalation.

Evidence rule: fresh output at the current HEAD; the rubric (rubric in prompts.ts) rejects narration and stale summaries.

Exports: EvaluationError, EvaluationTimeoutError, EvaluatorVerdictError, Evaluator.

src/runtime/evaluator.ts
