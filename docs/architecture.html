Architecture

Data flow

User→Event Router→Controller→Evaluator→Session
Controller→StoreEmitterBackground

Router fans server events to controller and background tracker (src/runtime/events.ts:31). Controller is the state machine (src/runtime/controller.ts:69). Evaluator judges each turn (src/runtime/evaluator.ts:30). Store persists one record per session (src/runtime/store.ts:26).

State machine

set → active → evaluate → continue / met / impossible; paused / failed / cleared (src/runtime/controller.ts:61).

StateMeaningSource
activeGoal live, turns run and evaluatesrc/core/types.ts:2
pausedWaiting for user promptsrc/runtime/controller.ts:475
achievedVerdict metsrc/runtime/controller.ts:360
impossibleVerdict impossiblesrc/runtime/controller.ts:365
clearedUser cleared or replacedsrc/runtime/controller.ts:182
failedFatal error, must fix first (terminal, distinct from cleared)src/runtime/controller.ts:399

Live states: active, paused (src/core/types.ts:27).

Ports

Controller depends only on narrow ports, so core stays host-agnostic (src/runtime/ports.ts:1). SessionPort, EvaluatorPort, BackgroundPort, StoragePort, EmitterPort, Clock, Logger (src/runtime/ports.ts:15).
