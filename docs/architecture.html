Architecture

Data flow

User→Event Router→Controller→Evaluator→Session
Controller→StoreEmitterBackground

Router fans server events to controller and background tracker (src/runtime/events.ts:32). Controller is the state machine (src/runtime/controller.ts:72). Evaluator judges each turn (src/runtime/evaluator.ts:38). Store persists one record per session (src/runtime/store.ts:26).

State machine

set → active → evaluate → continue / met / impossible; paused / failed / cleared (src/runtime/controller.ts:72).

StateMeaningSource
activeGoal live, turns run and evaluatesrc/core/types.ts:2
pausedPaused; a user message (or a resumed turn) clears it. Stall, turn cap, retry exhaustion, interrupt or a rate limit pause itsrc/runtime/controller.ts:661
achievedVerdict metsrc/runtime/controller.ts:401
impossibleVerdict impossiblesrc/runtime/controller.ts:403
clearedUser cleared or replacedsrc/runtime/controller.ts:197
failedFatal error, must fix first (terminal, distinct from cleared)src/runtime/controller.ts:586

Live states: active, paused (src/core/types.ts:44).

Ports

Controller depends only on narrow ports, so core stays host-agnostic (src/runtime/ports.ts:1). SessionPort, EvaluatorPort, BackgroundPort, StoragePort, EmitterPort, Clock, Logger (src/runtime/ports.ts:15).
