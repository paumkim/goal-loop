Architecture

Data flow

User→Event Router→Controller→Evaluator→Session
Controller→StoreEmitterBackground

Router fans server events to controller and background tracker (src/runtime/events.ts · createRouter()). Controller is the state machine (src/runtime/controller.ts · GoalController). Evaluator judges each turn (src/runtime/evaluator.ts · Evaluator). Store persists one record per session (src/runtime/store.ts · GoalStore).

State machine

set → active → evaluate → continue / met / impossible; paused / failed / cleared (src/runtime/controller.ts · GoalController).

StateMeaningSource
activeGoal live, turns run and evaluatesrc/core/types.ts · GoalStatus
pausedPaused; a user message resumes it. Interrupt (user) or an explicit maxTurns cap pauses it (plain goals only; an armed /goal-loop never pauses at the cap or stall guard; one notice each, the loop keeps running)src/runtime/controller.ts
achievedVerdict metsrc/runtime/controller.ts · evaluate()/finish()
impossibleVerdict impossiblesrc/runtime/controller.ts · evaluate()/finish()
clearedUser cleared or replacedsrc/runtime/controller.ts · clear(), src/runtime/controller.ts · arm()
failedFatal error, must fix first (terminal, distinct from cleared)src/runtime/controller.ts · handleFailure()

Live states: active, paused (src/core/types.ts · LIVE_STATUSES).

Ports

Controller depends only on narrow ports, so core stays host-agnostic (src/runtime/ports.ts). SessionPort, EvaluatorPort, BackgroundPort, StoragePort, EmitterPort, Clock, Logger (src/runtime/ports.ts · SessionPort).
