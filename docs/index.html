FAQ

Why did the goal pause?

Only Esc (pause), a terminal provider error (failed), or /goal clear stops an armed loop. The maxTurns and stallTurns caps are opt-in and apply to plain goals only (default 0 = off). An armed /goal-loop never pauses at either cap. It emits a one-time warning notice and keeps running. Rate limits are retried every 15 minutes, forever. Transient errors use capped exponential backoff. Zero-tool iterations and evaluator crashes never pause.

What is /goal-loop?

/goal-loop <objective> arms a /goal as usual. On a met verdict, the loop summarizes the achieved iteration into a short machine-consumable block. The evaluator then proposes the next, harder goal and arms it immediately.

The loop ends on /goal-loop clear, an impossible verdict, maxLoops completed iterations (default 5), a LOOP_COMPLETE reply (nothing worth improving), or an unsatisfiable step. An unsatisfiable step means the evaluator cannot summarize or plan, or a planner keeps repeating an already-completed condition.

Each iteration arms with a fresh compacted context and fires one info toast. The end of the loop fires one achieved toast.

You can override the iteration cap for a single run with /goal-loop-<N> <objective> or /goal-loop=N <objective>. The count must be an integer from 1 to 1000 and never becomes part of the condition. An invalid count is stated, and the configured default applies. The override never rewrites the configured default.

When does a goal stop?

It stops on a met or impossible verdict, on /goal clear, or on a fatal error (auth, credit, context, model). The terminal states are achieved, impossible, cleared and failed. failed (unrecoverable error) is distinct from cleared (you ended it). Neither is resumable (src/core/types.ts · GoalStatus, src/runtime/controller.ts · handleFailure()).

What is an epoch?

An epoch is a per-session counter bumped when new work starts, so stale async evaluations and timers drop their results instead of racing (src/runtime/controller.ts · Runtime.epoch, src/runtime/controller.ts · stale()).

What is a synthetic steer prompt?

A plugin-generated continuation sent with steer delivery (not a user message) that tells the agent the next turn and the evaluator reason (src/runtime/controller.ts · continueWith(), src/core/prompts.ts · continuation()).
