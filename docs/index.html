FAQ

Why did the goal pause?

Pause causes include 3 turns without tool use, rate or usage limits, an interrupt (Esc), or transient failures retried up to maxRetries times. Send any message to resume. The turn cap (200) pauses and stays paused until /goal clear or a new goal; a message will not extend it (src/runtime/controller.ts:257, src/runtime/controller.ts:455, README.md:53).

What is /goal-loop?

/goal-loop <objective> arms a /goal as usual, but on a met verdict the loop summarizes the achieved iteration into a short machine-consumable block and the evaluator proposes the next, harder goal, which is armed immediately. It ends on /goal-loop clear, an impossible verdict, maxLoops completed iterations (default 5), a LOOP_COMPLETE reply (nothing worth improving), an evaluator that keeps failing, or two consecutive zero-tool-call iterations. Each iteration fires one info toast; the end of the loop fires one achieved toast.

When does a goal stop?

It stops on a met or impossible verdict, on /goal clear, or on a fatal error (auth, credit, context, model). Terminal states are achieved, impossible, cleared, failed — failed (unrecoverable error) is distinct from cleared (you ended it) and neither is resumable (src/core/types.ts:2, src/runtime/controller.ts:665).

What is an epoch?

An epoch is a per-session counter bumped when new work starts, so stale async evaluations and timers drop their results instead of racing (src/runtime/controller.ts:41, src/runtime/controller.ts:408).

What is a synthetic steer prompt?

A plugin-generated continuation sent with steer delivery (not a user message) that tells the agent the next turn and the evaluator reason (src/runtime/controller.ts:461, src/core/prompts.ts:164).
