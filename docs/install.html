Install and use

Viewing these docs

This site is static HTML/CSS with no build step and no internet. Double-click docs/index.html in your file manager, or run xdg-open docs/index.html from the repo root. Keep the whole docs/ folder together — pages use relative links.

Install

opencode plugin add @el4cteo/opencode-goal

Requires OpenCode ≥2.0.29 (package.json:37). From GitHub: opencode plugin add github:EL4CTEO/opencode-goal. Local clone in opencode.json:

{ "plugins": ["/path/to/opencode-goal"] }

Commands

CommandAction
/goal <condition>Set goal and start immediately
/goalShow status
/goal statusShow status
/goal clearRemove goal (aliases: stop, off, reset, none, cancel)
/goal bun test passes with 0 failures and no test file is modified

Parsing: src/core/parse.ts:13.

opencode.json options

{
  "plugins": [{
    "package": "@el4cteo/opencode-goal",
    "options": {
      "evaluator": { "model": "opencode-go/deepseek-v4.1-flash" },
      "maxTurns": 200, "stallTurns": 3, "checkinMinutes": 30,
      "maxRetries": 3, "requireCommit": true, "commitBranch": "dev", "coordinator": "auto"
    }
  }]
}

Full table: Config. In coordinator repos (term) coordinator: "auto" (default) switches normal agents to wt/<slug> + submit / merge-next instead of a direct dev commit; true forces it, false disables it. Only the coordinator agent promotes dev -> main via script/land.ts.

Troubleshooting

Pause reasons

Interrupt, stall (3 turns w/o tool use), rate limit, non-retryable error. Send any message to resume. Turn cap (200) pauses and stays paused until /goal clear or a new goal; a message will not extend the cap (src/runtime/controller.ts:475, README.md:50).

Failed recovery

Fatal errors (auth 401/403, credit 402, context 413, model 404) fail the goal (status failed, distinct from cleared). Fix the cause, run /goal again; sending a message does not resume a failed goal (src/core/errors.ts:37, src/runtime/controller.ts:399).
